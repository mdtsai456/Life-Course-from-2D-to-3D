# UX 微調：拖放上傳 & 處理狀態文字

## Problem Frame

目前的上傳方式只有點擊選檔，缺少拖放支援，不夠直覺。處理中的回饋只有 spinner + 簡短文字，使用者不確定目前進行到哪一步。

## Requirements

**拖放上傳**
- R1. 兩個頁面（移除背景、圖片轉 3D）的上傳區域都支援拖放檔案
- R2. 拖放時顯示視覺提示（例如邊框高亮），讓使用者知道可以放下
- R3. 拖放的檔案需經過與點擊上傳相同的驗證（格式、大小）
- R4. 處理中時禁用拖放，與現有的 disabled 行為一致

**處理狀態文字**
- R5. 移除背景頁面：處理中顯示「正在移除背景，請稍候…」
- R6. 圖片轉 3D 頁面：兩個步驟分別顯示「步驟 1/2：正在移除背景…」和「步驟 2/2：正在轉換 3D 模型…」
- R7. 狀態文字取代現有的簡短「處理中…」文字，不額外增加 progress bar

## Success Criteria

- 使用者可以直接把圖片拖進上傳區域完成上傳
- 處理過程中，使用者能清楚知道目前在做什麼

## Scope Boundaries

- 不做進度百分比（後端不支援串流進度）
- 不做多檔案拖放（一次只處理一張）
- 不做歷史紀錄或其他功能
